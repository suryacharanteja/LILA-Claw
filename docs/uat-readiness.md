# Phase 1 UAT readiness

Status: business UAT pending. M3 worker/AI engineering verification is in progress.

The first integrated business UAT handoff is planned for M5, after the client screens, backend and M4 browser workflow are connected and their developer checks pass. This is a milestone dependency, not a calendar commitment. M3/M4 component checks remain engineering verification; the owner does not need to manually call internal APIs to accept an unfinished user journey.

Each usable handoff will include the exact build, launch/reset steps, supported scenarios, numbered cases with expected results, automated evidence, known limitations and a Pass/Fail feedback template. Cases will cover task configuration, missing-fact review, prepared-action review, pause/resume and visible outcomes as supported by that increment. Any external action requires the applicable action authorization; fixture results do not establish a real-platform outcome.

After owner feedback, defects are fixed and affected checks repeated. Engineering verification, owner UAT and release approval remain separate statuses. M8 includes full integrated Phase 1 UAT before release. Phase 2 and Phase 3 follow Phase 1 in the approved order.
